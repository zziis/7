ZILZAL v8 - خطوات التحديث
==========================

تم تعديل المشاكل المتفق عليها:
1) لم يعد الدخول كزائر تلقائياً. عند عدم وجود جلسة حساب تظهر شاشة تسجيل الدخول / إنشاء حساب / زائر.
2) القائمة الجانبية تغلق عند الضغط خارجها، بزر X، أو عند اختيار أي عنصر.
3) النوافذ المحمية وتسجيل الدخول تظهر فوق القائمة، وتغلق القائمة أولاً.
4) الفراشة أصبحت بحركة أوضح، واستلام 50 نقطة يعيد عداد 24 ساعة ويعرض رسالة نجاح.
5) صفحة حسابي: الاسم، الصورة، ID ثابت، النقاط، عضو منذ، البريد، تغيير كلمة المرور، الهاتف قريباً، تسجيل خروج.
6) صورة الحساب تُحفظ في Supabase Storage وتنعكس على القائمة وعلى هوية المستخدم داخل الرومات المحلية.
7) ID والنقاط لا توجد لهما أزرار تعديل، ودالة تعديل الحساب لا تستطيع تغييرهما.

مهم جداً بعد رفع الملفات إلى GitHub:
A) افتح Supabase > SQL Editor وشغّل ملف: supabase-fix-v8.sql مرة واحدة فقط.
B) أعد نشر Edge Function: auth-login من المسار supabase/functions/auth-login/index.ts
   لأن النسخة الجديدة لا تعيد ضبط عداد الفراشة عند كل تسجيل دخول.
C) امسح Cache المتصفح أو افتح الموقع في نافذة خاصة عند الاختبار الأول.

ملاحظة أمان:
لا يمكن ولا يجب عرض كلمة المرور القديمة المخزنة. زر العين يعرض فقط كلمة المرور الجديدة التي يكتبها المستخدم قبل حفظها.
