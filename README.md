# ⚡ ZILZAL - المنصة الرقمية الحديثة المتكاملة

منصة ويب عصرية وخارقة بتصميم مستقبلي نيون (Cyberpunk Glassmorphism)، تجمع بين الترفيه، التفاعل المجتمعي، والتقنية الذكية في واجهة واحدة متناسقة وسريعة الاستجابة.

![ZILZAL Platform](assets/images/logo.jpg)

---

## ✨ المميزات الرئيسية للمنصة

### 1. 📢 شريط الإعلانات والأخبار العلوي المتحرك
- شريط علوي أنيق يتحرك بسلاسة **من اليسار إلى اليمين** لعرض العواجل والإعلانات والتنبيهات.
- يدعم التوقف المؤقت عند تمرير مؤشر الفأرة (Hover to pause).
- إمكانية التحكم في سرعة الشريط من قائمة الإعدادات.

### 2. ⚡ هوية المنصة والشعار التعريفي
- شعار نيون ثلاثي الأبعاد متوهج بتأثيرات بصرية حديثة باسم **ZILZAL**.
- حالة حية للخادم والاتصال (Live Status Indicator).

### 3. 📲 الدخول إلى حساباتي الرسمية
- بطاقات سريعة ومصغرة أسفل اسم المنصة للوصول المباشر إلى:
  - 📢 **قناة تليجرام (Telegram Channel)**: تحديثات مستمرة وقاعدة مشتركين نشطة.
  - 📸 **انستغرام (Instagram)**: يوميات وتغطيات رقمية.
  - 👥 **فيسبوك (Facebook)**: مجتمع ومناقشات تفاعلية.
  - 🎵 **تيك توك (TikTok)**: فيديوهات قصيرة وترندات وشروحات.
- تشمل ميزة النسخ السريع للمعرفات والفتح المباشر.

### 4. 🧭 القائمة الجانبية الذكية (Sidebar Navigation)
قائمة مصغرة وقابلة للتوسيع تحتوي على 7 أقسام رئيسية:
1. ⚙️ **الإعدادات (Settings)**: التحكم في السمات اللونية (Cyan, Purple, Gold)، المؤثرات الصوتية التفاعلية، سرعة الشريط، وتخصيص الاسم المستعار والرمز التعبيري.
2. 💬 **رومات خاصة (Private Rooms)**: غرف دردشة حية تفاعلية (الروم العام، روم الجيمرز، روم VIP والمطورين) مع ردود مجتمعية ذكية.
3. 🎮 **الألعاب (Games)**:
   - 🚀 **سفينة الفضاء (Zilzal Space Defender)**: لعبة أركيد كلاسيكية مع إطلاق ليزر وحفظ أعلى سكور.
   - 🔢 **زلزال 2048 (Zilzal 2048 Neon)**: لعبة دمج أرقام بألوان نيون مبهرة.
   - ❌ **إكس أو (Tic-Tac-Toe vs AI)**: تحدي الذكاء الاصطناعي مع لوحة نتائج تفاعلية.
4. 📺 **مسلسلات (Series)**: مكتبة مسلسلات مصنفة مع عارض الحلقات وتفاصيل المواسم.
5. 🎬 **أفلام (Movies)**: استعراض سينمائي عالي الجودة بدقة 4K HDR مع فلاتر البحث السريع حسب التصنيف.
6. 🤖 **بوت ذكاء اصطناعي (Zilzal AI)**: مساعد ذكي تفاعلي للإجابة الفورية، كتابة الأكواد، النطق الصوتي (TTS)، واقتراحات سريعة.
7. 📱 **تطبيقات APK (APK Store)**: متجر مخصص لتحميل أحدث التطبيقات والألعاب المعدلة بروابط مباشرة وفحص أمني معتمد.

## 🚀 طريقة التشغيل محلياً (Local Run)

المنصة مبنية بأحدث معايير الويب الخفيفة ولا تتطلب أي تثبيت معقد أو حزم خارجية (Zero-Config):

1. **التشغيل المباشر**:
   - يمكنك فتح ملف `index.html` مباشرة بالنقر المزدوج في أي متصفح حديث (Chrome, Edge, Firefox, Safari).

2. **التشغيل عبر سيرفر محلي (اختياري)**:
   ```bash
   # باستخدام بايثون:
   python -m http.server 8000
   ```
   ثم افتح المتصفح على: `http://localhost:8000`

### تفعيل TMDB

> ملاحظة: TMDB يوفر بيانات وصور وتريلرات وليس بث الأفلام الكاملة. لأي تشغيل كامل استخدم فقط محتوى تملك حق عرضه أو مصدرًا مرخصًا.

- إزالة بطاقات APK الوهمية من المتجر.

- إذا أردت أن تظهر الإضافات لكل الزوار ومن أي جهاز، فالخطوة التالية هي ربط لوحة APK بـ Supabase.


## v6.1 — متجر APK مربوط بـ Supabase
1. افتح Supabase > SQL Editor وشغّل `supabase.sql`.
2. افتح `supabase-config.js`.
3. ضع Project URL و anon/public key.
4. ارفع الملفات على GitHub Pages.
5. أي تطبيق تضيفه من لوحة المطور سيظهر لكل الزوار وعلى جميع الأجهزة، وRealtime يحدث المتجر فورًا.

### تنبيه
صلاحيات SQL في هذه النسخة مفتوحة للإضافة/التعديل/الحذف لتسهيل التجربة. قبل نشر المنصة للعامة يجب ربط لوحة المطور بتسجيل دخول مدير وتقييد RLS.


## v6.2 — تسجيل مدير حقيقي
- أضفنا تسجيل دخول مدير عبر Supabase Auth بالبريد وكلمة المرور.
- زر «إدارة المطور» لا يفتح لوحة الإدارة إلا إذا كان الحساب موجودًا في جدول `apk_admins`.
- صلاحيات الإضافة والتعديل والحذف أصبحت محمية بـ RLS من قاعدة البيانات نفسها.
- الزوار يستطيعون مشاهدة التطبيقات المنشورة فقط.
- المدير يستطيع مشاهدة التطبيقات المخفية وإدارتها.

### إعداد حساب المدير لأول مرة
1. افتح Supabase → Authentication → Users.
2. أنشئ مستخدمًا بالبريد وكلمة المرور.
3. افتح SQL Editor وشغّل `supabase.sql`.
4. بعد ذلك نفّذ:
```sql
insert into public.apk_admins(user_id)
select id from auth.users
where email='بريد_المدير@example.com'
on conflict (user_id) do nothing;
```
5. افتح المنصة → APK → دخول المدير، ثم أدخل نفس البريد وكلمة المرور.

مهم: لا تستخدم `service_role` داخل ملفات GitHub أو JavaScript. استخدم فقط anon/public key في `supabase-config.js`.

## v7 — التحديث الموحد
أضيف: بوابة تسجيل/زائر، ID المطور 1 والمستخدمون من 1000، نقاط ودعوات، فراشة 50 نقطة/24 ساعة و+2 للداعي، +10 عند تسجيل المدعو، حسابي/محفوظات/إشعارات/دعوة/دعم، حسابات رسمية قابلة للطي، شريط إعلان مستمر، لعبة الفضاء ملء الشاشة وسحب باللمس، وZILZAL BOT مع 10 أسئلة Gemini جديدة يوميًا لكل حساب مع بقاء الردود المخزنة مجانية.

### تشغيل Supabase
1. شغّل `supabase.sql` في SQL Editor.
2. ضع Project URL و anon key في `supabase-config.js`.
3. انشر Edge Functions الموجودة في `supabase/functions/`: `auth-register`, `auth-login`, `zilzal-bot`.
4. أضف Secret باسم `GEMINI_API_KEY` إذا أردت الردود الذكية، وSecret باسم `DEV_SETUP_SECRET` لإنشاء حساب المطور لأول مرة.
5. **لا تضع service_role داخل GitHub**؛ Edge Functions تحصل عليه من بيئة Supabase فقط.

### حساب المطور ID 1
واجهة التسجيل العادية تنشئ المستخدمين من 1000 فما فوق. حساب المطور ID 1 محجوز ويجب إنشاؤه مرة واحدة بشكل إداري عبر Edge Function باستخدام `DEV_SETUP_SECRET` (لا تشارك السر). بعد إنشائه، الدخول الطبيعي يكون ID = 1 + كلمة المرور.

### ملاحظة مهمة عن تسجيل الخروج والفراشة
كما طُلب: بقاء الجلسة مسجلة يجعل العداد يستمر. بعد تسجيل خروج حقيقي، أول تسجيل دخول جديد يعيد `reward_ready_at` إلى 24 ساعة من وقت الدخول.
